# Notas 0.1.3

- Accepting a macOS word suggestion with Tab keeps the cursor and text in place. Autosave preserves active accents and unfinished input.
- A gear menu opens Settings, shows the installed version, and checks GitHub for updates. An Update button appears when a newer release is available.
- Updates download and replace the app only after notes have saved and Notas has quit.
- Pasting several lines preserves lists and code blocks, and pasting over selected title text replaces it correctly.
- Tables return after Undo and when scrolled back into view. Tab moves between table cells and text columns.
- Sketches keep their proportions when the window changes size. Copied text that includes an image pastes as text.
- Note deletion asks for confirmation. Return cancels the confirmation.
- Storage fixes preserve edits and notebook changes made on two Macs, retain recovery copies, and handle notes still downloading from iCloud.
- Quick Note restores focus to the previous app. Failed shared captures are retained and reported once.

Requires an Apple Silicon Mac with macOS 26 or newer. This build is not notarized and does not include the widgets or Share extension.

If your copy has no update controls, quit Notas and run the install command in the README once.
